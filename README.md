# 🌊 Осуши Бассейн — 3D симулятор воды

3D-игра на Three.js: огромный бассейн с реалистичной шейдерной водой, которую нужно осушать, зачерпывая воду и продавая её продавцу.

## Запуск

Нужен любой статический сервер (из-за ES-модулей), например:

```bash
npx serve .
# или
python3 -m http.server 8000
```

Затем открой `http://localhost:8000` (или порт, который выдал сервер). Требуется интернет — Three.js подгружается с CDN.

## Геймплей

| Действие | Управление |
|---|---|
| Ходить | WASD (Shift — бег) |
| Смотреть | Мышь |
| Зачерпнуть воду | ЛКМ, стоя у края и глядя на воду |
| Продать воду / открыть магазин | E (магазин ещё и B) |
| Сменить инструмент | 1 — ложка, 2 — стакан, 3 — таз |

## Экономика

| Инструмент | Цена | Доход за черпок |
|---|---|---|
| Ложка | есть с начала | $1 |
| Стакан | $20 | $5 |
| Таз | $50 (открывается в магазине) | $15 |
| Насос | $30 (до 8 шт.) | $3 каждые 8 сек, сам откачивает воду |

Воду нужно относить продавцу (NPC у бассейна) — он платит деньги. Уровень воды в бассейне реально падает по мере откачки. Цель — осушить бассейн полностью.

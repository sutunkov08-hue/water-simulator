# 🌊 Осуши Бассейн — 3D симулятор воды

3D-игра на Three.js: огромный бассейн с реалистичной водой (шейдерные волны, отражения), который нужно осушать, зачерпывая воду и продавая её скупщику. В воде можно плавать и нырять.

## Запуск

```bash
npx serve .
# или
python3 -m http.server 8000
```

Открой адрес сервера в браузере (нужен интернет — Three.js грузится с CDN).

## Режимы (главное меню)

| Режим | Бассейн | Вода (условные ед.) |
|---|---|---|
| 🌱 Лёгкий | 24×16 м | 250 |
| 🏊 Стандартный | 40×25 м | 1000 |
| 🔥 Сложный | 64×40 м | 3000 |
| 💀 Невозможный | 500×300 м (полкилометра!) | 200 000 |

## Управление

| Действие | Клавиши |
|---|---|
| Ходить / плыть | WASD (Shift — бег) |
| Смотреть | Мышь |
| Зачерпнуть воду | ЛКМ у воды |
| Нырнуть / всплыть | Ctrl в воде |
| Выбраться из бассейна | Пробел у края |
| Продать воду / магазин | E (магазин ещё и B) |
| Сменить инструмент | 1 ложка · 2 стакан · 3 таз · 4 канистра |

## Экономика

| Предмет | Цена | Доход | Влияние на уровень воды |
|---|---|---|---|
| Ложка | есть сразу | $1 | почти незаметно |
| Стакан | $20 | $5 | заметно |
| Таз | $50 | $15 | хорошо видно |
| Канистра | $200 | $30 | очень заметно |

| Прокачка насосов | $50, 100, 150, 200 (макс. ур. 5) | — | цикл быстрее, объём больше |

Игра проходит **в закрытом помещении** — бассейном зале со стенами, потолком и рядами световых панелей под потолком.

Рядом с точкой появления игрока стоят два киоска:
- 🏪 **Магазин** (красно-белый тент, вывеска «МАГАЗИН») — продавец продаёт инструменты.
- 🚰 **Скупка воды** (бирюзовый киоск с оранжевой крышей, вывеска «СКУПКА ВОДЫ») — скупщик покупает воду, в другом углу той же стороны.

Бежать через всю карту не нужно: оба киоска на ближней стороне бассейна. Уровень воды падает с каждым черпком; когда бассейн осушен — победа и возврат в главное меню.
